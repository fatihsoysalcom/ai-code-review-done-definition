# AI Code Review 'Done' Definition

This Python script simulates a basic AI code reviewer to illustrate the concept of defining 'done' in code. It analyzes code snippets for common issues and reports whether they meet a simplified 'done' criterion.

## Language

`python`

## How to Run

Run this Python script using: python ai_code_review_done.py
